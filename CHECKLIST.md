### M66 — THE ISLAND MOVES (the second half of the fidelity sweep)
- [x] **Water has had swell, flow, foam and churn since M12. Nothing else on the island moved at all** — every blade of the grass carpet, every fern, bush, reed, flower and kelp frond was nailed rigid. That is the loudest "this is a render, not a place" signal a game can give, and it is the honest reading of the user's "lack of animations in places"
- [x] **One shared vertex patch, `wind.ts`.** The bend is driven by **world position**, not instance index, so neighbours move together in gusts rather than each blade doing its own thing — that coherence is the whole difference between wind and jitter. Two travelling waves (a long gust rolling across the island, a short flutter on top), scaled by height up the blade so the root stays planted. Per-kind amplitude: grass 6 cm, ferns 5, flowers 6, reeds 9, **kelp 14** (water drags more than air); stone, trunks and mushrooms stand still
- [x] **The cache-key rule from M54 held**: the amplitude is a **uniform**, so the key gets a bare `|wind` marker and never the value — otherwise it would be one byte-identical program per sway amount, which is exactly the bug M54 closed
- [x] **Proving it took more care than building it.** A running world moves for a dozen reasons — animals, water, the day clock — so a "did the frame change?" test proves nothing. The gate **freezes the world** (`dt = 0`, everything stops) and then advances **only the wind clock**: anything that changes is the wind and nothing else. Same clock value → byte-identical frame, which also protects the determinism `gate-settings` has relied on since M46
- [x] **"Weird billboards sometimes" — found and fixed.** A mid-band impostor is a side-on sprite mirrored to match the animal's facing, and the test was a bare `Math.sin(rel) < 0`. When an animal walks straight toward or away from you `sin(rel)` sits at zero, so the smallest wobble in its heading **snapped the sprite left-right, repeatedly** — a distant animal visibly stuttering between two mirror images. It holds its last decision until the heading is decisively the other way (±0.15), and the flip is released with the slot
- [x] **The cost, measured honestly.** `gate-perf` read the plain at 8.66 ms against 4.88 earlier and the machine was at load average **35** — so instead of arguing, a `setWindScale(0)` knob (no recompile) A/B'd it against itself, four alternating samples per spot: plain **6.31 off / 7.01 on**, wood line **6.11 off / 6.05 on**. The two OFF samples differ by as much as OFF differs from ON. **The wind's cost is below the noise floor**, and the earlier number was contention, not the change
- [x] **Gate (m3, +6)**: at the plain, the wood and the seabed — the same wind clock renders an identical frame, and advancing only the wind moves it

### M67 — UNDER THE WATER LOOKS LIKE UNDER THE WATER (the sweep's last finding)
- [x] **Swimming looked exactly like walking.** Four metres below the sea, looking up: a clear blue sky with **clouds** in it.
